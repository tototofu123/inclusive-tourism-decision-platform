# Inclusive Tourism Decision Platform

Private hackathon project for an AI-powered decision intelligence platform that helps tourists with special physical needs plan accessible, safe, and enjoyable itineraries in Kowloon first, then all of Hong Kong.

This repo is organized into 5 version folders:

- `version-mvp-web/`
- `version-web-v1/`
- `version-web-v2/`
- `version-app-v3/`
- `version-app-final/`

Each version folder contains guides and specifications for architecture, agents, flows, and implementation details.
