# Files Needed – Web v2

This document lists additional files for Web v2.

- Cloud config files for Vertex AI, Vector Search, BigQuery.
- `src/services/cloudAiGateway.ts` – wraps ADK and Vertex AI calls.
- `src/services/cloudRag.ts` – handles cloud RAG queries.
- Environment and secret management files for Google credentials.

These build on Web v1 and connect the app to Google Cloud.
