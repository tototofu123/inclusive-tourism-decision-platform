# Guide – App v3

This document describes the goals of App v3.

## Goal
Introduce a mobile app that:
- Syncs itineraries from the backend.
- Provides offline access to current itinerary and basic map data.
- Supports a wake word for hands-free interaction.
- Tracks live location to adapt routes.

App v3 runs alongside the web app, sharing the same backend and cloud AI.
